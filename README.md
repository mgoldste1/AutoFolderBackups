# AutoFolderBackups
It monitors a folder and if there have been changes to it, it will clone it to the backup dir.


Useful for backing up some video game saves.  

Examples: 

1. Stardew valley - It automatically backs up your save every time you go to bed so you end up with a backed up save for every day. Then if you realize you needed to do something 3 days ago you can revert.
2. Games in alphas/betas - The game isnt stable yet and your save might randomly get corrupted. This happened to me a few times and this app made it so I didnt need to start over.
